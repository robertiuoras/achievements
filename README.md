# achievements

A sandbox repo used to test GitHub API automation — creating issues, pull requests and discussions programmatically with `gh` and the GraphQL API.

Nothing here is a product. Real work lives at [taskdriver.ai](https://taskdriver.ai), [PaneForge](https://github.com/robertiuoras/PaneForge) and [QuitOnClose](https://github.com/robertiuoras/quitonclose).
